# DRAFT: Departures for the ledger and income design

Proposed on 13 November 2026 with `docs/design/ledger-income.md`. **Nothing here is
decided.** Each row is a difference between the canvas as it stands
(`docs/design/vibrant-canvas.html`) and the new boards
(`docs/design/ledger-income-boards.html`). The rows are written in the format of the
Departures table in `docs/design/conformance.md`, with the status `proposed`.

When the build of step 6a lands, each row the owner accepts moves into `conformance.md`
and its status changes there. A row the owner rejects is deleted here, and the design
changes to match the canvas.
